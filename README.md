# Home Kiosk

Home Assistant OS에서 독립적으로 실행하는 홈 대시보드 앱입니다. React 화면, 사진·폰트, HA 연결 서버와 물리 디스플레이용 브라우저를 함께 설치합니다. 기존 Web Kiosk 앱이나 맥 개발 서버에 연결하지 않습니다.

## 설치와 실행

HA에서 **설정 → 앱 → 앱 스토어 → 메뉴 → 저장소**에 다음 주소를 추가합니다.

```text
https://github.com/korellas/home-kiosk
```

**Home Kiosk**를 설치하고 시작한 뒤 **웹 UI 열기 → 연결 설정**에서 기기와 알림 소리를 선택합니다. 기존 Web Kiosk 앱은 중지하고 자동 시작을 해제합니다.

## 로컬 설치 패키지

로컬 앱 설치용 패키지를 만듭니다.

```sh
npm ci
npm test
npm run deploy
```

`dist/home-kiosk-app.zip`의 `home-kiosk` 폴더를 HAOS의 `/addons/home-kiosk`에 복사합니다. 앱 스토어에서 업데이트를 확인하고 **Local apps → Home Kiosk**를 설치·시작합니다. 이 패키지는 필요한 화면 파일을 포함하며 HA 장비에서 컨테이너를 빌드합니다. 최초 설치와 업데이트 이미지·패키지를 받을 때는 인터넷이 필요합니다.

HA의 앱 페이지에서 **웹 UI 열기 → 연결 설정**으로 접속합니다. 기기 이름이나 엔티티 ID로 검색해 필요한 항목만 연결하고 **저장하고 적용**을 누릅니다. 선택을 지우면 연결이 해제됩니다. 기존 초인종·카메라 설정은 유지되며 설정은 앱 내부의 `connection.json`에 저장됩니다.

- **현관:** 호출 전용 `event` 또는 `binary_sensor`, 현관 `camera`를 선택합니다.
- **공간별 기기:** 조명을 공간에 배치하고 HA 장면을 연결합니다. 거실에는 커튼·냉난방·미디어 플레이어를 연결할 수 있습니다.
- **환경 센서:** 온도·습도·공기질 센서, 날씨와 환기 팬을 선택합니다. 화면에 사용하는 센서 측정 단위를 확인하세요.
- **소리:** 키오스크 벨소리와 HA 외부 스피커 안내를 각각 켜고 테스트합니다. 외부 스피커는 `media_player`와 `tts` 음성 엔진을 함께 선택합니다.

키오스크 벨소리는 파이에 연결한 스피커로 출력합니다. HA 앱의 오디오 설정에서 출력 장치를 선택하세요. 설정 화면의 **이 기기에서 벨소리 듣기**는 현재 브라우저에서 소리를 내므로, 다른 컴퓨터에서 열었다면 그 컴퓨터의 스피커가 울립니다. HA 외부 스피커 안내는 앱 서버가 처리하여 대시보드가 닫혀 있어도 동작합니다. 현재 스피커 음량을 사용하며 기기에 따라 음악이 중단될 수 있습니다. 인터넷 없이 음성 안내를 사용하려면 HA의 로컬 음성 엔진과 내부 연결로 동작하는 스피커가 필요합니다.

앱 옵션은 루트 `config.json`에서 정의합니다. `kiosk`가 켜져 있으면 장비에 연결된 디스플레이에 같은 대시보드를 표시합니다. HA 웹 UI만 사용할 경우 끕니다. 화면 방향은 `rotation`, 상세 로그는 `debug`에서 설정합니다. `debug` 모드에서는 기기 내부 Chromium 진단도 활성화됩니다. HA 관리자는 진단 API로 화면 전환을 자동 비교할 수 있으며, 측정 중에는 기기 화면이 잠시 바뀝니다. 진단 후에는 `debug`를 끄고 재시작합니다. 기존 Web Kiosk와 동시에 디스플레이를 점유하지 않도록 기존 앱은 중지하고 자동 시작을 해제합니다.

## 실행 구조

**우리 집 → 화면 → 테마**에서 기본 디자인과 글래스를 전환합니다. 선택한 테마는 현재 브라우저에 저장됩니다.

HA 사이드바에서는 **Ingress**를 거쳐 앱 화면을 엽니다. 물리 키오스크 브라우저는 앱 컨테이너 안의 루프백 주소를 엽니다. 두 경로 모두 같은 앱 서버와 정적 화면을 사용하므로 맥이나 외부 CDN 없이 실행됩니다. HA 연결이 끊겨도 앱 서버는 화면 파일을 계속 제공하고, 화면에 연결 끊김을 표시합니다. 초인종·카메라를 실제로 사용하려면 HA와 해당 장비 사이의 내부 연결이 필요합니다.

앱 서버는 Supervisor의 Core 프록시를 통해 HA 상태를 구독합니다. `SUPERVISOR_TOKEN`은 서버에서만 사용하며 브라우저·공개 저장소·연결 설정에 넣지 않습니다. 브라우저에는 선택한 엔티티의 상태만 전달합니다. 카메라 요청도 서버가 선택된 카메라로만 중계합니다.

Ingress 요청은 Supervisor에서 온 연결만 신뢰합니다. 설정 조회·변경은 Ingress 사용자 ID를 HA 사용자 목록과 대조하여 활성 관리자인지 확인합니다. 사용자 ID가 없거나 권한 확인에 실패하면 설정을 허용하지 않습니다. 물리 키오스크에서는 설정에 연결된 기기를 조작할 수 있습니다. 설정 변경과 외부 스피커 테스트는 HA 관리자 웹 UI에서만 허용합니다. 서버는 선택한 대상과 지원하는 명령만 전달합니다. 일반 LAN 접근을 위한 별도 호스트 포트는 열지 않습니다.

## 초인종과 화면 동작

초인종의 새 호출이 오면 대기·청소 모드를 해제하고 화면 크기에 맞춘 현관 호출 화면을 표시합니다. 호출 이력이 없는 이벤트 엔티티의 첫 호출도 감지하며, 초기 접속·재연결 시 과거 호출을 다시 울리지 않습니다. 카메라는 HA의 이미지를 주기적으로 갱신합니다. 통화·오디오·문 열기는 구현 범위에 포함하지 않습니다. 호출 기록은 현재 열린 화면 세션의 기록입니다.

메인 화면은 원본 목업 비율에 맞춰 표시합니다. 상세 창에서 필요한 스크롤은 스크롤바를 숨깁니다. 공간 전환은 좌우 스와이프, 조명 상세 공간 전환은 가로 화면에서 상하·세로 화면에서 좌우 스와이프를 사용합니다. 대기모드는 화면 상세에서 직접 진입하거나 `IDLE_TIMEOUT_MS` 동안 조작이 없으면 진입합니다.

대기모드에서는 시계·실내 온도·라벨을 한 묶음으로 유지하며, 화면 안의 무작위 위치로 주기적으로 옮깁니다.

기기 슬라이더는 조작 중 설정할 값을 보여주고, 손이나 조작 키를 놓으면 명령을 보냅니다. 요청값은 기기에서 보고한 값과 구분해 상태 확인 중으로 표시하며 실패하면 실제 값으로 돌아갑니다. 화면 밝기와 벨소리 음량 설정은 조작 중 바로 반영됩니다. 기기 버튼은 요청 중 해당 버튼에 진행 표시를 보여주며, 다른 기기의 제어는 계속 사용할 수 있습니다.

실제 기기 연결은 `HomeAdapter`를 통해 분리합니다. 독립 앱에서는 설정에서 선택한 기기의 실제 상태와 지원 기능을 반영합니다. 미연동·사용 불가·미지원 제어는 비활성화하며, 명령을 보낸 것만으로 기기 상태를 변경해 표시하지 않습니다. 환기 팬은 지원하는 속도와 자동 모드를 제어하며 강풍 타이머는 HA 자동화에서 구성합니다. 화면 밝기 설정은 물리 패널의 백라이트를 제어하지 않습니다.

## 개발과 검증

```sh
npm run dev
```

개발 서버는 `vite.config.ts`에 따라 `0.0.0.0`에 바인딩합니다. 개인 개발 호스트명을 허용해야 할 때는 Vite의 `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS` 환경변수를 로컬 실행 환경에 설정합니다. 해당 설정은 저장소에 기록하지 않습니다. 데모 화면은 `createDemoAdapter`, 독립 앱 화면은 `createHassAdapter`와 앱 서버를 사용합니다.

```sh
npm test
npm run build:app
python3 scripts/package_app.py
```

빌드 산출물은 `dist/app`에 생성합니다. 입력이 바뀌지 않았다면 기존 빌드를 재사용해 패키지만 다시 만들 수 있습니다. `npm run deploy`는 설치 패키지 생성 명령이며, 기기에 설치하거나 레지스트리에 게시하지 않습니다.

## 이미지 배포

`config.json`의 `version`과 `image`가 이미지 배포의 기준입니다. GitHub Actions는 테스트와 프런트엔드 빌드를 수행한 뒤 같은 산출물로 ARM64 앱 이미지를 빌드합니다. 검토한 커밋에서 워크플로를 수동 실행하고 `publish`를 선택하면 검증 후 이미지를 게시합니다. 공개한 버전은 덮어쓰지 말고 버전을 올려 배포합니다.

사용자는 HA 앱 스토어에서 업데이트를 적용하면 됩니다. 저장된 연결 설정은 이미지 밖의 앱 데이터에 있으므로 이미지와 함께 초기화되지 않습니다. 로컬 설치 패키지는 레지스트리 이미지 대신 포함된 파일로 빌드하도록 구성합니다.

## 출처

화면은 제공된 Home Screen v3 목업을 바탕으로 구현했습니다. 로컬 사진과 폰트 라이선스는 `public`에 포함합니다. Cage·Chromium 실행, 터치 회전 패치와 디스플레이 점검은 `haos-web-kiosk` 구현을 참고·재사용했으며 해당 MIT 라이선스를 포함합니다. 기존 Web Kiosk 저장소는 변경하지 않습니다.
